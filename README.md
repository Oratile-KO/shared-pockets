# shared-pockets
A Python application for managing flexible stokvel contributions, loans, repayments and member settlements.

## About

This project is being developed as a practical Python learning project
based on a real-world stokvel.

The stokvel allows members to contribute flexible amounts without a
fixed monthly contribution requirement. The group also allows external
borrowers, as well as members, to borrow from the collective pool.

## Current Features

- Member management
- Contribution tracking
- Contribution totals

## Planned Features

- Persistent data storage
- SQLite database
- External borrower management
- Member loans
- Loan repayments
- Member settlements
- Financial reports
- Data visualization
- Web interface
- Authentication
- Automated testing
